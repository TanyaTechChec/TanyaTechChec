## Коммерческий опыт

### Ответо — сервис коммуникаций с покупателями

Работаю в QA-команде над веб-сервисом обработки обращений и подготовки ответов с использованием ИИ.

- Проверяю пользовательские сценарии, настройки и шаблоны ответов.
- Тестирую фильтрацию, сортировку, состояния интерфейса, аналитику и выгрузки.
- Исследую поведение ИИ на разных входных данных.
- Проверяю ролевые ограничения и оформляю воспроизводимые описания дефектов.

### МПГО — система управления операционными процессами

Работаю в QA-команде с пользовательскими кабинетами и административным интерфейсом.

- Создаю и структурирую тест-кейсы в Allure TestOps.
- Проверяю бизнес-правила, расчёты и финансовые операции.
- Тестирую роли, ограничения доступа, формы и валидации.
- Проверяю поиск, навигацию и согласованность состояний в разных интерфейсах.

На текущих проектах пишу сценарии, самостоятельно тестирую API и участвую в дежурствах по проектам.
